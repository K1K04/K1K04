## 🚀 Proyectos Destacados

### 🛡️ WP VulnScanner Pro — TFM
> Escáner de vulnerabilidades WordPress full-stack con inteligencia artificial integrada.

- 🐍 Backend Python/Flask con API REST y autenticación por API Key
- 🔍 16 módulos de análisis + módulo activo (brute force / probing)
- 📊 Dashboard en tiempo real con D3.js y Chart.js
- 📄 Exportación a PDF/Excel
- 🤖 IA integrada via SSE (Claude API)
- 🗄️ Base de datos CVEs (NVD, Patchstack, WPScan)
- 🐳 Despliegue con Docker Compose

### 🔒 WP Sentinel Security — Plugin WordPress
> Plugin de seguridad activa para WordPress con arquitectura orientada a objetos.

- 🏗️ Arquitectura OOP en PHP
- ⏱️ Rate Limiting con sliding window
- 🔑 Gestión avanzada de sesiones
- 🛡️ Security Headers automáticos
- 🧱 WAF con reglas regex personalizables

### 🔄 Pipeline DevSecOps — Jenkins + Docker + K8s
> Pipeline CI/CD con seguridad integrada en cada fase del ciclo de vida.

- ⚙️ Jenkins con stages: build → SAST → DAST → deploy
- 🔍 Análisis estático con SonarQube
- 🐳 Escaneo de imágenes Docker con Trivy
- ☸️ Despliegue automatizado en Kubernetes (k3s)
- 📢 Alertas integradas vía webhook

### 📡 Lab SIEM — Wazuh + Elastic Stack
> Laboratorio de detección y respuesta ante incidentes con stack completo.

- 🔎 Wazuh como agente IDS/HIDS
- 📥 Ingesta de logs con Logstash + Beats
- 🗃️ Indexación en Elasticsearch
- 📊 Dashboards de amenazas en Kibana
- 🚨 Reglas de correlación y alertas personalizadas

### 🌐 Lab Monitorización — GNS3
> Infraestructura de red monitorizada con telemetría streaming.

- 📈 InfluxDB + Telegraf + Prometheus + Grafana
- 🔒 gNMI sobre TLS
- 🐳 Docker Compose
